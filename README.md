# Multiplayer Platform Shooter

An older **Unity/C# multiplayer prototype** exploring server-authoritative gameplay and custom networking before Unity's newer networking stack matured.

Built in **Unity 2018.2.6f1**.

## Areas explored

- Server-authoritative multiplayer game-session structure
- Client/server networking using Unity's legacy networking APIs
- Team deathmatch session logic
- Spawn management and team-aware spawn points
- Weapon and projectile systems
- ScriptableObject-based weapon data
- Cinemachine camera integration
- Audio and general gameplay systems

This repository is preserved as an earlier networking/gameplay experiment. It represents the implementation approach and Unity APIs available at the time rather than how I would structure a new multiplayer project today.
